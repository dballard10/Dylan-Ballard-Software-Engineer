---
name: handoff
description: End-of-session handoff — save state for the next session
---

Perform an end-of-session handoff. Complete ALL of the following steps:

1. **Update `.scratchpad/status.md`**:
   - Set "Last updated" to today's date
   - Move completed items from "In Progress" to "Completed"
   - Update "In Progress" with the current state of any unfinished work
   - Update "Next Up" with what the next session should prioritize
   - Update "Known Issues" if anything new was discovered

2. **Append to `.scratchpad/session-log.md`**:
   - Add a new entry with today's date
   - List what was accomplished (bullet points)
   - Note any blockers encountered
   - State what the next session should tackle first

3. **Update `.scratchpad/decisions.md`** (if applicable):
   - Add any non-obvious decisions made this session
   - Include the rationale (Why) and alternatives considered
   - This prevents future sessions from re-debating settled questions

4. **Update `.scratchpad/blockers.md`** (if applicable):
   - Add any new blockers discovered
   - Move resolved blockers to the "Resolved" section with date
   - Include workarounds for active blockers

5. **Report the handoff summary** to the user:
   - What was done
   - What is still in progress
   - What the next session should start with
   - Any open questions or decisions needed from the user
